          Sobre o projeto

          Feito por estudantes da FATEC Mogi das Cruzes

          O MONITORAÊ é um projeto da disciplina de Engenharia de Software II do curso de Análise e Desenvolvimento de Sistemas. A ideia é acompanhar, depois das eleições, o trabalho de quem foi eleito e de quem é pago com dinheiro público na cidade.

          Um web crawler desenvolvido pela equipe coleta automaticamente os dados dos portais oficiais da Prefeitura e da Câmara, e o site apresenta essas informações de forma clara para qualquer cidadão.

          Professor orientador: Leandro Luque.
